# oplix-uptime

Внешняя проверка доступности https://oplix.ru/.

Раз в 5 минут GitHub Actions открывает сайт (до 3 попыток). Если сайт не
отвечает кодом 200 — уведомление в Telegram; пока не отвечает — напоминание
раз в час; когда снова отвечает — сообщение с длительностью простоя.

- `.github/workflows/uptime.yml` — проверка;
- `.github/workflows/keepalive.yml` — чтобы GitHub не отключил расписание
  после 60 дней без активности.
